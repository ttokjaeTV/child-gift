# 자녀 증여 계산기 · 똑재TV

자녀에게 언제, 얼마씩 증여하면 증여세 없이 줄 수 있는지 계산하고, 증여한 돈을 굴렸을 때 아이가 받게 될 금액과 '나중에 한 번에 줄 때' 증여세를 비교하는 계산기.

- 사이트: https://ttokjaetv.github.io/child-gift/
- 근거: 상속세 및 증여세법(2025-10-01 시행본, 2026-10-24 국가법령정보센터 원문 확인) — 제26조·제56조 세율, 제47조② 10년 합산(직계존속은 배우자 포함 동일인), 제53조 증여재산공제(직계존속 → 미성년 2천만·성년 5천만, 10년 합계), 제53조의2 혼인·출산 1억, 제55조② 과세최저한 50만원, 제57조 세대생략 할증 30%, 제58조 납부세액공제, 제69조② 신고세액공제 3%.
- 제도 숫자는 허브 `rules/v2026.3/rules.js`의 `GIFT`(v2026.3에서 추가)에서 읽는다.
- 증여 방법: 10년마다 공제 한도만큼 / 매달 적립(한 해치를 그해 증여 한 번으로 묶음) / 직접 입력 5칸 + 혼인·출산 공제. 증여세는 받은 돈에서 내고 나머지를 굴림.
- 넣지 않은 것: 자녀 계좌 운용 중 세금·수수료, 정기금 평가, 상속 시 사전증여 가산(제13조).

## 수정하는 법
`src/`를 고친 뒤 `python src/build.py` → `index.html`. 시험 `node src/test.js`(기대값은 법령 손계산).
